03 / METHOD

How we build

Five principles, all visible in the public code.

  1. 01

    Durable state beats clever prompting.

    Hard problems get solved with versioned files on disk — ledgers, timelines, knowledge bases — not longer prompts. No agent depends on its memory of a prior session.

  2. 02

    The generator never verifies its own work.

    Producer and reviewer are separate agents, ideally on separate platforms with separate failure modes.

  3. 03

    Standards must be measurable to be enforceable.

    Numeric caps and countable rules, not adjectives. "Use sparingly" is not a standard; "no more than two per document, counted mechanically" is.

  4. 04

    Fail loud.

    A system that cannot complete its checks blocks; it never returns a confident default. Incomplete evidence is a verdict, and that verdict is no.

  5. 05

    The human gate is a feature.

    Throughput comes from the agents; judgment does not. A named person owns every decision that ships.
